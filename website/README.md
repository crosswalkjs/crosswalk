# Crosswalk docs

The documentation site, built with [Docusaurus](https://docusaurus.io/) and published to https://crosswalkjs.github.io/crosswalk/.

It embeds the real editor and generates the operator reference from the built packages, so build those first:

```bash
npm install && npm run build   # in the repo root
cd website
npm install
npm start                      # http://localhost:3000/crosswalk/
```

`docs/operators/reference.mdx` is generated by `scripts/operators-reference.mjs` before every start and build. Edit the operators or the script rather than the file.
